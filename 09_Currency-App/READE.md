 
Döviz Kuru Uygulaması (React)
Bu proje, güncel döviz kurlarını anlık olarak takip etmenizi ve farklı para birimleri arasında çeviri yapmanızı sağlayan modern bir web uygulamasıdır. React öğrenme sürecimde geliştirdiğim, API entegrasyonu ve state yönetimini içeren bir çalışmadır.



Özellikler
Anlık Veri: Free Currency API üzerinden güncel verileri çeker.

Hızlı Çeviri: USD, EUR ve TRY arasında anlık kur hesaplaması yapar.

Modern UI: Temiz ve kullanıcı dostu arayüz tasarımı.

Responsive: Farklı ekran boyutlarına uyumlu yapı.



Kullanılan Teknolojiler
React: Bileşen tabanlı kullanıcı arayüzü geliştirme.

Axios: API isteklerini yönetmek için kullanılan promise tabanlı HTTP istemcisi.

React Icons: Uygulama içindeki ikonlar için.

CSS3: Özel stil ve layout tasarımları.
